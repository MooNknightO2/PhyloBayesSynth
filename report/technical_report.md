# PhyloBayesSynth
## 1. 概述
基于域特定语言（DSL）的系统发育概率程序合成系统。给定系统发育树的拓扑结构和枝长数据，系统通过贝叶斯推断自动发现最优的进化模型和参数，而非事先固定模型形式。
将进化模型表示为上下文无关文法生成的表达式树，在表达式空间上执行 MCMC / SMC 采样，通过似然函数评估每个候选表达式对观测数据的拟合程度。

## 2. 上下文无关文法

### 2.1 文法规则

```
N1 := (NoisyPhylo N2 N3)
N2 := (Noise σ)
N3 := (CRB λ)
    | (CRBD λ μ)
    | (TDB λ₀ z)
    | (TDBD λ₀ z ε)
    | (BAMM η N3 N3)
```

其中 N1 是起始符号，N2 控制观测噪声，N3 是进化模型的递归产生式。BAMM 产生式允许嵌套（最大 3 层），使文法能表达分段异质的过程。

### 2.2 模型族

| 模型 | 参数 | 出生率 | 死亡率 | 特征 |
|------|------|--------|--------|------|
| CRB | λ | 恒定 λ | 0 | Yule 纯生模型 |
| CRBD | λ, μ | 恒定 λ | 恒定 μ | 恒定出生-死亡 |
| TDB | λ₀, z | λ₀·exp(z·(T−τ)) | 0 | 时变出生率，无灭绝 |
| TDBD | λ₀, z, ε | λ₀·exp(z·(T−τ)) | ε·λ(τ) | 时变出生-死亡，恒定 turnover |
| BAMM | η, bg, fg | 取决于子模型 | 取决于子模型 | 泊松变点切换 |

退化关系：
- CRBD(λ, μ=0) = CRB(λ)
- TDBD(λ₀, z, ε=0) = TDB(λ₀, z)
- TDB(λ₀, z=0) = CRB(λ₀)
- BAMM(η=0, bg, fg) = bg
- BAMM(η, M, M) = M

### 2.3 先验分布

| 参数 | 先验 | 说明 |
|------|------|------|
| λ | Exp(scale=0.15) | 出生率，均值 0.15 |
| μ | Exp(scale=0.08) | 死亡率，均值 0.08 |
| z | N(0, 0.5) | 时间趋势，允许正负 |
| ε | Beta(2, 6) | μ/λ 比，集中在 0.25 附近 |
| η | Exp(scale=0.03) | 切换速率 |
| σ | Exp(scale=0.08) | 噪声水平，鼓励低噪声 |

N3 产生式的选择概率：CRB 25%, CRBD 25%, TDB 20%, TDBD 20%, BAMM 10%。

## 3. 似然函数

### 3.1 时间约定

- τ 表示距今时间（age）：present = 0，root = T
- 前向时间 t = T − τ：root = 0，present = T
- 树是仅含现生物种的重构树（reconstructed tree），共 2n−2 条枝、n−1 个分支事件

### 3.2 CRB — 闭式计算

CRB 是纯生模型（μ=0），有解析闭式：

$$\log \mathcal{L}(\lambda) = \log \Gamma(n) + (n-1)\log\lambda - \lambda S$$

其中 S 是总枝长。不需要根存活条件化（灭绝概率 E=0）。

### 3.3 TDB — 闭式计算

TDB 是时变纯生模型（μ=0），也有解析闭式：

$$\log \mathcal{L}(\lambda_0, z) = \log \Gamma(n) + \sum_{k=1}^{n-1} \log\lambda(\tau_k) - \sum_{i=1}^{2n-2} \Lambda(\tau_c^{(i)}, \tau_p^{(i)})$$

其中 Λ(a,b) = ∫ₐᵇ λ(τ) dτ 有解析表达式。同样不需要根条件化。

### 3.4 CRBD / TDBD / BAMM — ODE 统一框架

#### 3.4.1 灭绝

在出生-死亡过程中，我们只观测到存活到现世的谱系（重构树），但进化过程中实际上产生了大量灭绝分支——它们在树上不可见。似然函数必须"整合掉"所有可能的灭绝历史。

为此需要两个量：
- **E(τ)**：一条谱系在距今 τ 时刻存在，但在 τ 到 0（现世）之间完全灭绝的概率
- **D(τ)**：观测到的树的子结构在距今 τ 时刻的概率密度

E 表示"灭绝了多少看不见的分支"，D 表示"看得见的这棵树有多大概率以这种形状出现"。

#### 3.4.2 多状态速率系统

对于 CRBD 这样的模型，系统只有 1 个状态——在任意时刻，每条谱系的出生率和死亡率都相同。

对于 BAMM，一条谱系可以处于 bg（背景）或 fg（前景）两种 regime 之一。每种 regime 有自己的出生率和死亡率。这样系统有 2 个状态（如果 bg/fg 本身是 BAMM，状态数还会递归增长）。

状态间的切换用转移速率矩阵 Q 描述：

```
        bg状态   fg状态
bg状态 [ -η       η    ]    ← bg 以速率 η 切换到 fg
fg状态 [  0       0    ]    ← fg 不会切换回 bg（不可逆）
```

Q 矩阵的性质：每行之和为 0（Q[i,i] = −Σ_{j≠i} Q[i,j]），保证概率守恒。

对于嵌套 BAMM（例如 bg 本身是一个 BAMM），bg 子系统有 2 个子状态，fg 也有若干子状态，总状态数 = n_bg + n_fg。Q 矩阵按块对角拼接内部切换，再在 bg 块到 fg 块之间添加外层切换速率 η。

#### 3.4.3 灭绝概率 ODE

**物理含义**：E_i(τ) 是一条在时刻 τ 处于状态 i 的谱系，在 [0, τ] 期间完全灭绝（包括所有子孙）的概率。

从现世 (τ=0) 向根 (τ=T) 积分。边界条件 E(0) = 0：一条在现世还存在的谱系，"从现在到现在"灭绝的概率是 0。

在微小时间 dτ 内，状态 i 的谱系可能发生以下事件：

1. **死亡**（速率 μ_i）：谱系直接灭绝，贡献 μ_i · dτ
2. **出生**（速率 λ_i）：产生两条子谱系，两条都必须灭绝才算"完全灭绝"，概率为 E_i²，贡献 λ_i · E_i² · dτ
3. **无事件**（速率 λ_i + μ_i + Σ跳出速率）：谱系继续存在且留在状态 i，带着已知的灭绝概率 E_i 往前走，贡献 −(λ_i + μ_i − Q_{ii}) · E_i · dτ
4. **状态切换**（速率 Q_{ij}，j≠i）：谱系跳到状态 j，之后以 E_j 的概率灭绝，贡献 Q_{ij} · E_j · dτ

合在一起：

$$\frac{dE_i}{d\tau} = \mu_i - (\lambda_i + \mu_i - Q_{ii}) E_i + \lambda_i E_i^2 + \sum_{j \neq i} Q_{ij} E_j$$

**单状态特例（CRBD）**：Q = [0]，方程简化为经典形式 dE/dτ = μ − (λ+μ)E + λE²。

代码使用 `scipy.integrate.solve_ivp` 的 BDF（向后差分）方法求解这个刚性 ODE 系统，并生成 dense output（连续函数 e_sol(τ)），以便在后续 D 传播中任意时刻插值 E 的值。

#### 3.4.4 D 向量传播 ODE

**物理含义**：D_i(τ) 是"以节点 τ 为根的可见子树"在状态 i 下的概率密度。计算是后序（自底向上）遍历树。

**叶节点**（现生物种，τ_leaf ≈ 0）：D = 1。含义：一个现生物种在现世存在的概率密度就是 1（归一化基准）。

**沿枝传播**：从子节点 τ_c 向父节点 τ_p 传播 D。在微小 dτ 内：

1. **无出生、无死亡、不切换**：谱系安静存在，D 以 −(λ_i + μ_i − Q_{ii}) 的速率衰减（因为这段时间没有产生可见事件，但可能产生了不可见旁支并全部灭绝）
2. **不可见旁支的贡献**：速率 λ_i 的出生事件可能产生一条旁支并灭绝（概率 E_i），这不改变可见树结构但修正概率，贡献 +2λ_i · E_i · D_i
3. **状态切换**：贡献 Q_{ij} · D_j

合在一起：

$$\frac{dD_i}{d\tau} = -(\lambda_i + \mu_i - Q_{ii} - 2\lambda_i E_i) D_i + \sum_{j \neq i} Q_{ij} D_j$$

直观理解：D 沿枝衰减的速率是 (λ+μ−2λE)——出生率和死亡率使 D 减小（因为需要"这段枝上没有可见事件"），但 2λE 项补偿了"不可见旁支产生并灭绝"的概率。

**内部节点合并**：当两条枝汇聚到一个内部节点（分叉事件）时：

$$D_{\text{node}} = \lambda \cdot D_{\text{left}} \cdot D_{\text{right}}$$

含义：分叉事件本身贡献一个出生率因子 λ，然后左右子树的概率密度相乘（独立事件）。

#### 3.4.5 根似然

$$\log \mathcal{L} = \underbrace{\log \Gamma(n)}_{\text{标记历史排列数}} + \underbrace{\log D_{\text{root}}[s_0]}_{\text{可见树的概率密度}} - \underbrace{2 \log(1 - E(T)[s_0])}_{\text{根存活条件化}}$$

- $\Gamma(n) = (n-1)!$：n 个叶节点的标记树有 (n−1)! 种可能的分叉顺序（拓扑常数）
- $D_{\text{root}}[s_0]$：自底向上传播得到的根节点概率密度，$s_0$ 是根状态（对 BAMM 是 bg 的初始状态）
- $-2\log(1 - E(T))$：冠群存活条件化。根产生两条初始谱系，我们观测到的树要求两条都存活到现世。给定根在距今 T 时刻，每条谱系存活的概率是 $1 - E(T)$，两条独立存活的概率是 $(1-E(T))^2$。

#### 3.4.6 一个具体例子

考虑用 CRBD(λ=0.09, μ=0.02) 计算一棵 4 叶树的似然：

```
      root (τ=2.0)
      ├── i1 (τ=1.0)
      │   ├── A (τ=0)
      │   └── B (τ=0)
      └── i2 (τ=1.0)
          ├── C (τ=0)
          └── D (τ=0)
```

**第 1 步：求解灭绝 ODE**，从 τ=0 到 τ=2：
- E(0) = 0
- dE/dτ = 0.02 − 0.11·E + 0.09·E²
- 得到连续函数 E(τ)

**第 2 步：自底向上传播 D**：
- 叶节点 A,B,C,D: D = 1
- 沿枝 A→i1 传播（τ: 0→1）：求解 dD/dτ = −(0.11 − 0.18·E(τ))·D，得 D_A_up
- 同理 B→i1: D_B_up
- 内部节点 i1: D_i1 = λ · D_A_up · D_B_up = 0.09 · D_A_up · D_B_up
- 同理得 D_i2
- 沿枝 i1→root 传播，沿枝 i2→root 传播
- 根节点: D_root = λ · D_i1_up · D_i2_up

**第 3 步：组装**：
- log L = log(3!) + log(D_root) − 2·log(1 − E(2.0))

#### 3.4.7 BAMM 的多状态 ODE 详细展开

下面以一个单层 BAMM(η, bg=CRBD(λ_b, μ_b), fg=CRBD(λ_f, μ_f)) 为例，展示多状态 ODE 的完整方程。

**状态定义**：

- 状态 0 = bg（背景 regime），出生率 λ_b，死亡率 μ_b
- 状态 1 = fg（前景 regime），出生率 λ_f，死亡率 μ_f

**切换矩阵 Q**：

$$Q = \begin{pmatrix} -\eta & \eta \\ 0 & 0 \end{pmatrix}$$

bg 以速率 η 切换到 fg（Q[0,1]=η），fg 不能切换回 bg（Q[1,0]=0）。对角线满足行和为零：Q[0,0]=−η，Q[1,1]=0。

**灭绝 ODE（2 维系统）**：

$$\frac{dE_0}{d\tau} = \mu_b - (\lambda_b + \mu_b + \eta)\,E_0 + \lambda_b\,E_0^2 + \eta\,E_1$$

$$\frac{dE_1}{d\tau} = \mu_f - (\lambda_f + \mu_f)\,E_1 + \lambda_f\,E_1^2$$

边界条件：$E_0(0) = E_1(0) = 0$。

逐项解读 $dE_0/d\tau$：
- $\mu_b$：谱系在 bg 状态下直接死亡
- $-(\lambda_b + \mu_b + \eta)\,E_0$：谱系在 bg 状态下"安静存在"（没有出生、没有死亡、没有切换），以已知灭绝概率 $E_0$ 继续演化。分母中多了 $\eta$ 是因为谱系还可能切换走
- $\lambda_b\,E_0^2$：谱系在 bg 状态下出生，产生两条子谱系，两条都灭绝（各自概率 $E_0$，所以乘积 $E_0^2$）
- $\eta\,E_1$：谱系从 bg 切换到 fg，之后以 fg 的灭绝概率 $E_1$ 灭绝

注意：$E_1$ 的方程不依赖 $E_0$（因为 fg 不会切回 bg），所以 **fg 方程可以独立求解**，它就是标准的 CRBD Riccati 方程，有解析解。但 **bg 方程依赖 $E_1(\tau)$**，即使 $E_1$ 有解析解，代入后 bg 方程仍是一个系数随时间变化的 Riccati 方程，一般没有闭式解，必须数值求解。

**D 传播 ODE（2 维系统）**：

$$\frac{dD_0}{d\tau} = -(\lambda_b + \mu_b + \eta - 2\lambda_b E_0)\,D_0 + \eta\,D_1$$

$$\frac{dD_1}{d\tau} = -(\lambda_f + \mu_f - 2\lambda_f E_1)\,D_1$$

逐项解读 $dD_0/d\tau$：
- $-(\lambda_b + \mu_b + \eta - 2\lambda_b E_0)\,D_0$：谱系在 bg 状态下沿枝传播，速率包括出生、死亡、切换的"消耗"，以及不可见旁支产生并灭绝的"补偿"（$2\lambda_b E_0$ 项）
- $\eta\,D_1$：如果谱系从 bg 切换到 fg，后续子树的密度贡献从 $D_1$ 流入

$D_1$ 的方程同样不依赖 $D_0$（单向耦合）。

**叶节点边界条件**：$D_0 = D_1 = 1$（所有状态下，现生物种在现世的密度为 1）。

**内部节点合并**：

$$D_{\text{node},\,i} = \lambda_i \cdot D_{\text{left},\,i} \cdot D_{\text{right},\,i}, \quad i \in \{0,\,1\}$$

在每个状态下独立做分叉合并。

**根似然**：根节点从 bg 状态出发（$s_0 = 0$）：

$$\log \mathcal{L} = \log \Gamma(n) + \log D_{\text{root}}[0] - 2\log(1 - E_0(T))$$

#### 3.4.8 嵌套 BAMM 的状态空间扩展

当 BAMM 的子模型本身也是 BAMM 时，状态空间递归扩展。例如：

```
BAMM(η₁,
  bg = BAMM(η₂, bg_inner=CRB(λ₁), fg_inner=CRBD(λ₂, μ₂)),
  fg = CRBD(λ₃, μ₃)
)
```

- 内层 BAMM 有 2 个状态：{bg_inner, fg_inner}
- 外层 bg = 内层 BAMM = 2 个状态，外层 fg = CRBD = 1 个状态
- 总状态数 = 2 + 1 = 3

Q 矩阵（3×3）：

$$Q = \begin{pmatrix} -\eta_2 - \eta_1 & \eta_2 & \eta_1 \\ 0 & -\eta_1 & \eta_1 \\ 0 & 0 & 0 \end{pmatrix}$$

- 状态 0（bg 块的 bg_inner）：可以内层切换到状态 1（速率 η₂），也可以外层切换到状态 2（速率 η₁）
- 状态 1（bg 块的 fg_inner）：只能外层切换到状态 2（速率 η₁）
- 状态 2（fg 块的 CRBD）：吸收状态，不再切换

对应的灭绝 ODE 和 D 传播 ODE 都是 3 维系统，结构与 2 维情形完全类似，只是维度增加。代码通过递归构建自动处理任意嵌套层数（上限 3 层）。

#### 3.4.9 ODE 求解方法

使用 `scipy.integrate.solve_ivp` 的 **BDF（Backward Differentiation Formula）** 方法，而非显式 Runge-Kutta。

选择 BDF 的原因：灭绝 ODE 中的 $\lambda E^2$ 项使方程非线性，当 $E$ 接近 1（高灭绝率）时方程呈刚性（stiff）——不同方向的特征时间尺度差异极大。显式方法（如 RK45）在刚性问题上被迫使用极小步长，效率很低。BDF 是隐式多步法，每步通过 Newton 迭代求解非线性方程，可以在保持稳定性的同时使用大步长。

关键求解器参数：
- `rtol=1e-7, atol=1e-9`：相对/绝对误差容限
- `max_step`：限制最大步长，灭绝 ODE 为 max(1e-3, T/300)，D 传播为 max(1e-3, ℓ/80)
- `dense_output=True`（仅灭绝 ODE）：生成连续插值函数 $E(\tau)$，供 D 传播时在任意 τ 处查询

### 3.5 观测噪声模型

采用污染混合（contamination mixture）模型：

$$\mathcal{L}_{\text{final}} = (1-\pi) \cdot \mathcal{L}_{\text{model}} + \pi \cdot \mathcal{L}_{\text{noise}}, \quad \pi = \frac{\sigma}{1+\sigma}$$

噪声基线分布 L_noise 是对 CRB 模型做 λ ~ Exp(β) 先验后的解析边际似然：

$$\mathcal{L}_{\text{noise}} = \frac{\beta \cdot [\Gamma(n)]^2}{(S + \beta)^n}, \quad \beta = 1/\text{scale}_\lambda$$

- σ=0 → π=0，完全信任结构化模型
- σ→∞ → π→1，退化为噪声基线

## 4. 数据生成

### 4.1 模拟流程

1. 初始化根节点，前向时间 t=0
2. 对每个活跃谱系，计算事件速率并采样下一个事件时间
3. 根据出生/死亡概率决定事件类型：出生产生两条子谱系，灭绝移除该谱系
4. 达到目标叶节点数 n_tips 时停止
5. 在停止时刻为所有活跃谱系创建现生叶节点
6. 剪枝：移除所有灭绝分支，压缩单子路径
7. 输出 phylojson 格式

### 4.2 时变速率的正确处理

#### 4.2.1  Gillespie？

标准 Gillespie 算法假设两次事件之间速率恒定：在当前时刻 t 计算总速率 R，然后采样等待时间 Δt ~ Exp(R)。这对 CRB/CRBD 完全正确（速率是常数），但对 TDB/TDBD 是错误的。

举例说明：假设出生率 λ(t) = 0.1·exp(0.5·t)，当前 t=0 时 λ=0.1。如果冻结速率 λ=0.1 来采样等待时间，平均等待时间 = 1/0.1 = 10。但实际上在 t=0 到 t=10 之间，λ 已经从 0.1 指数增长到 0.1·exp(5) ≈ 14.8——真实的平均等待时间远小于 10。冻结速率会系统性地高估等待时间、低估事件数量，导致生成的树枝长偏长、分叉偏少。

#### 4.2.2 累积速率反函数法

思想：指数分布等待时间的本质是"累积风险达到阈值时事件发生"。

对于恒定速率 R：等待时间 Δt ~ Exp(R) 等价于采样 u ~ Exp(1)，令 Δt = u/R。这是因为 ∫ R ds = R·Δt = u。

推广到时变速率：采样 u ~ Exp(1)，然后求解**累积速率方程**：

$$\int_t^{t'} R(s)\,ds = u$$

找到使累积速率恰好等于 u 的时刻 t'，这就是下一个事件的时间。

#### 4.2.3 事件后的处理

确定事件时间 t' 后，需要决定：

1. 哪条谱系发生了事件：由于所有 k 条谱系共享相同的时变速率（λ 只依赖时间不依赖谱系），均匀随机选取一条

2. 出生还是死亡：以事件时刻 t' 的瞬时速率为准
   - 出生概率 = λ(t') / (λ(t') + μ(t'))
   - 对 TDB：μ=0，必然是出生
   - 对 TDBD：μ(t') = ε·λ(t')，出生概率 = 1/(1+ε)

## 5. 推断算法

### 5.1 转移算子 Generate-New-Expression

每步以概率 p_local（默认 0.5）选择两种提议之一：

**局部参数随机游走**：
1. 均匀选取表达式中的一个参数位置
2. 用 Gaussian 随机游走扰动：θ' = θ + N(0, σ_step²)
3. MH 接受率：α = min{1, L(E')·prior(E') / (L(E)·prior(E))}

**结构剪枝重采样**：
1. 均匀选取解析树中的一个节点位置 a
2. 在 a 处剪枝，得到非终结符 N_i 和带空洞的表达式 E_sev
3. 从先验中采样新子树 E_sub ~ Expand(N_i)
4. 填充空洞得到 E' = E_sev[E_sub]
5. MH 接受率：α = min{1, (|A_E|/|A_{E'}|) · (L'/L)}

### 5.2 MCMC (Bayesian-Synthesis-MCMC)

```
输入: 树数据 D, 迭代次数 n
1. 从先验采样初始表达式 E₀，确保 L(E₀) > 0
2. 维护全局最优 (best_expr, best_log_L)
3. for i = 1 to n:
4.     E_i ← Generate-New-Expression(D, E_{i-1})
5.     定期评估并更新最优
6. 输出: 样本序列 E₁...Eₙ, 最优表达式, 模型后验频率
```

### 5.3 SMC (Bayesian-Synthesis-SMC)

采用顺序单观测切换方案（非标准累积后验 SMC）：

```
输入: 观测序列 O₁...O_J, 粒子数 M, rejuvenation 步数 n
1. 初始化 M 个粒子 ~ Prior
2. for j = 1 to J:
3.     Reweight: w_j ∝ ŵ_{j-1} · p(O_j|E) / p(O_{j-1}|E)
4.     Resample (adaptive, ESS < M/2)
5.     Rejuvenate: 对每个粒子执行 n 步 MH
```

增量权重为 p(O_j|E)/p(O_{j-1}|E)，每步从以 p(E|O_{j-1}) 为目标过渡到 p(E|O_j)。适用于多棵树逐个分析的场景。
